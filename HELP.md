# Simple Line Editor - Help

## Commands

I - Insert a new line
D - Delete a line
L - Display the document
Q - Quit the editor

## How to Insert a Line

Enter I.

Then enter the line number and the text.

Example:
I
1
Hello World

## How to Delete a Line

Enter D.

Then enter the line number.

Example:
D
1

## How to Display the Document

Enter L.

Example:
L

## How to Exit

Enter Q.

Example:
Q
