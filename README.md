## Project Description

This project is a simple command-line line editor developed in C.

The editor stores multiple lines of text and allows the user to insert, delete, and display lines.

## Features

- Insert a line
- Delete a line
- Display the document
- Quit the editor

## Data Structure

The program uses an array of character pointers to store the lines of the document.

## Commands

| Command | Function |
|---|---|
| I | Insert a line |
| D | Delete a line |
| L | Display document |
| Q | Quit |
